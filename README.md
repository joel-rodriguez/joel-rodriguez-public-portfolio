# joel-rodriguez-public-portfolio

Welcome! My name is Joel Rodriguez, and this repository serves as a central hub for my personal projects, open-source tools, and code experiments. 

## My Interests

My primary areas of interest and expertise include:
* **Web Development:** Front-end and back-end applications, interactive components, and web utilities. I am especially interested in the spring ecosystem.
* **Graphics Programming:** Projects utilizing OpenGL (and WebGL), shader development, rendering experiments, and visual computing.

## Purpose

The primary goal of this repository is to share codebases and utilities that can be:
* **Used** as standalone tools or educational references.
* **Modified** to fit specific requirements or workflows.
* **Adapted** into larger projects, engines, or frameworks.

Whether you are interested in web interfaces or low-level graphics rendering, you will find various scripts, mini-apps, and experimental builds documented here.

## Contents

* **Personal Projects:** Standalone applications and interactive graphics demos.
* **Utilities & Scripts:** Small tools designed for specific tasks and workflows.
* **Templates & Starter Code:** Reusable components and setup code for quick prototyping.
